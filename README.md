# Start From Lin

**A personal website and blog built with Hugo, hosted on Netlify.**

**Live Website:** [startfromlin.netlify.app](https://startfromlin.netlify.app/)

## About This Project

Start From Lin is my personal website and blog, created as a space to document my professional journey, share insights, and reflect on what I learn along the way.

Beyond personal branding, this website is also a hands-on project where I can develop and demonstrate my skills in website development, version control, deployment, and ongoing maintenance.

## Tech Stack

| Technology | Purpose |
|---|---|
| Hugo | Static site generator |
| Git & GitHub | Version control and source code management |
| Netlify | Website hosting and deployment |
| Markdown | Content creation and management |

## Project Objectives

- **Personal Branding:** Establish an online presence that reflects my professional background, interests, and development.
- **Knowledge Sharing:** Document experiences, lessons learned, and insights from my professional and learning journey.
- **Technical Practice:** Gain practical experience in managing a static website, including content updates, version control, and deployment.
- **Continuous Improvement:** Maintain and enhance the website over time as my skills and interests evolve.

## Project Status

This is an ongoing personal project. Content and website improvements will be introduced progressively.
